# 초보자를 위한 학습 안내

## 10살 아이에게 설명하면

카메라는 눈이 얼마나 열렸는지 봅니다. 시계는 눈을 감은 시간이 얼마나 긴지 잽니다. 기록장은 그 일을 저장합니다. 글을 쓰는 AI는 기록장을 읽고 다음 공부와 쉬는 계획을 제안합니다. AI가 사람의 마음이나 실제 집중력을 읽는 것은 아닙니다.

## 다섯 단계의 이해

1. **기초:** 사진 한 장으로 눈이 닫혀 보이는지는 볼 수 있지만 얼마나 오래 닫혔는지는 알 수 없습니다.
2. **측정:** 얼굴의 점 사이 거리를 비교해 눈 열림 비율 EAR를 구합니다. 사람마다 평소 눈 모양이 달라 기준을 보정합니다.
3. **시간:** 기준보다 작은 상태가 2초 이어질 때 이벤트를 확정합니다. 입력이 끊기면 그 사이 상태를 알 수 없어 연속 조건을 초기화합니다.
4. **학습:** 정리된 공부 통계와 좋은 코칭 문장을 여러 쌍 보여 주어 한국어 모델의 일부 파라미터를 조정합니다.
5. **평가:** 처음 보는 사람·상황에 고정된 모델과 규칙을 적용하고 정답 구간과 비교합니다. 개발 자료에서 좋아진 점수가 실제 환경에서도 유지되는지 확인합니다.

## 서로 다른 분야의 비유 세 가지

- **요리:** 공개 데이터는 재료입니다. 운전자 영상만으로 학생 필기까지 잘 구분한다고 가정하는 것은 국 재료로 빵을 그대로 만들려는 것과 비슷합니다. 목적에 맞는 재료가 필요합니다.
- **운동:** 일반 체육관에서 배운 동작을 내 경기장에서도 시험해야 합니다. 공개 영상 개발 후 내 맥북·책상에서 하는 소규모 검증이 경기장 적응입니다.
- **학교 시험:** 개발 자료는 연습문제, 검증 자료는 모의고사, 최종 시험 자료는 실제 시험입니다. 정답을 보고 풀이법을 고친 뒤 같은 문제로 실력을 평가하면 공정하지 않습니다.

## 흔한 실수 다섯 가지

| 실수 | 피하는 방법 |
|---|---|
| 사진을 많이 모으면 지속시간도 평가할 수 있다고 생각함 | 타임스탬프가 있는 연속 영상 사용 |
| 고개 숙임을 모두 졸음으로 셈 | 눈과 자세 이벤트 분리, 필기·가림 시험 |
| 같은 영상 프레임을 학습·시험에 나눔 | 참가자·원본 세션별 묶음 분리 |
| 얼굴 영상으로 코칭 LLM까지 학습하려 함 | 통계 입력·한국어 정답 문장 쌍 별도 제작 |
| main 병합이 팀원 컴퓨터에도 즉시 반영된다고 생각함 | 팀원이 최신 main을 pull, 미커밋 작업 먼저 확인 |

## 주간 학습 경로

| 주차 | 배울 내용 | 연습 | 점검 지점 |
|---|---|---|---|
| 1 | Python 함수·가상환경·Git 기본 | 영상 열기, 문서 변경 PR | PR과 merge와 pull 차이 설명 |
| 2 | 좌표·비율·시간·상태 | EAR 계산과 가상 시간 입력 | 깜박임과 지속 눈 감김 구분 |
| 3 | JSON·SQLite·데이터 품질 | 세션 저장, 합성 코칭 20건 검토 | 중복·관측 부족·모순 처리 |
| 4 | 사전 학습·미세 튜닝·LoRA | 작은 학습 후 저장·재로딩 | 어떤 파라미터가 변했는지 확인 |
| 5 | F1·시간 IoU·독립 시험 | 정답·예측 구간 매칭 | 틀린 사례와 한계 설명 |
| 6 | 통합·재현·검토 | 다른 팀원의 환경에서 실행 | 기록과 모델 결과 재현 |

6주만으로 모든 분야의 전문가가 되는 것은 아닙니다. 이 프로젝트의 결과를 설명하고 재현·검증할 수 있는 수준을 목표로 합니다. 이후 가림 강건성·시계열 모델·모델 평가 설계를 심화합니다.

## 난이도가 높아지는 연습 다섯 개

| 단계 | 문제 | 힌트 | 정답 |
|---|---|---|---|
| 1 | 눈 감은 사진 1장으로 2초 눈 감김을 증명할 수 있나요? | 시간 정보 | 아니요. 연속 관측과 시간이 필요합니다. |
| 2 | 평소 EAR가 0.30이면 65% 진입 기준은? | 0.30 × 0.65 | 0.195 미만입니다. |
| 3 | 눈 감김이 0초부터 유효하게 계속되고 2.1초에 처리됐다면 최초 확정 지연은? | 2초 조건 시각과 처리 시각 분리 | 0.1초. 실제 소리 출력이 더 늦으면 그 차이도 포함합니다. |
| 4 | 공부 60분, 미측정 10분, 눈 감김 합집합 5분이면 비율은? | 관측 시간 분모 | 5 ÷ 50 = 10%. 공부 시간 대비 8.33%와 다릅니다. |
| 5 | 정답 [10,14], 예측 [11,15]초가 한 쌍이면 시간 IoU는? TP=8, FP=2, FN=2의 F1은? | 겹침/합집합, 2TP/(2TP+FP+FN) | IoU=3/5=0.6, F1=16/20=0.8. 다른 중복 예측이 없는 일대일 대응을 가정합니다. |

## 이해도 점검 열 문제

먼저 답을 가리고 풀고 틀린 항목에 해당하는 문서를 복습합니다.

| 번호 | 질문 | 정답 | 복습할 부분 |
|---|---|---|---|
| 1 | 얼굴 모델을 처음부터 새로 학습해야 하나요? | 현재 설계에서는 사전 학습 MediaPipe 사용 | 구현 1단계 |
| 2 | 공개 영상의 ‘졸음’ 등급이 눈 감김 시작 시각인가요? | 아니요 | 데이터 정답 단위 |
| 3 | 고개를 숙이고 필기하면 무조건 졸음인가요? | 아니요 | 구현 3단계 |
| 4 | 얼굴이 안 보이면 EAR=0을 넣나요? | null·유효 여부·미측정 사유 사용 | 모듈 규칙 |
| 5 | 처리 속도가 절반이면 2초 기준도 4초로 바뀌나요? | 아니요, 실제 또는 영상 시간 사용 | 시간 기준 |
| 6 | 미측정 구간은 정상 관측인가요? | 아니요 | 관측 가능 시간 |
| 7 | 말만 바꾼 코칭 예시를 학습·시험에 나눠도 되나요? | 같은 원형 그룹에 유지 | 그룹 분할 |
| 8 | 모델 대신 규칙 문장이 나와도 학습 성공인가요? | 아니요, 대체 안내로 구분 | 코칭 평가 |
| 9 | PR을 main에 병합하면 모든 팀원 로컬 파일도 바뀌나요? | 각자 pull 필요 | 협업 방법 |
| 10 | 이슈를 생성하면 AI가 자동 구현하나요? | 별도 자동화 없이는 실행되지 않음 | 자동화 범위 |

1~3번이 틀리면 감지 목적·데이터를, 4~6번은 측정과 시간을, 7~8번은 학습·평가를, 9~10번은 GitHub 협업을 복습합니다.

## 일상 적용 예시와 기억 이야기

필기하다 고개를 숙였지만 눈이 보이고 떠 있다면 자세 이벤트만 기록합니다. 얼굴이 책에 가려지면 ‘졸음’ 대신 ‘측정 불가’를 보여 줍니다. 세션 후 코칭은 관측된 기록에만 근거해 다음 휴식 계획을 제안합니다.

책상 위에 **눈금자·시계·공책·선생님**이 있다고 상상하세요. 눈금자가 눈의 벌어짐을 재고, 시계가 오래 감겼는지 확인하고, 공책이 사실을 적습니다. 선생님은 공책을 읽고 조언합니다. 공책이 빈 구간에서는 선생님도 모른다고 말해야 합니다. ‘재고, 기다리고, 기록하고, 조언한다’로 기억합니다.

## 적용을 위한 작은 프로젝트 세 가지

1. **눈 열림 계기판:** 공개 영상 한 개에서 EAR 시간 그래프와 유효 여부를 CSV로 저장합니다. 눈을 가린 순간의 값이 0으로 오해되지 않으면 통과입니다.
2. **촬영 없는 판정 시험기:** 가상 시간과 EAR 목록으로 정상·깜박임·지속 감김·입력 중단을 재생합니다. FPS를 바꿔도 이벤트 시간이 같으면 통과입니다.
3. **세션 코칭 비교기:** 합성 세션 20건에 기본 모델·튜닝 모델·규칙 안내를 생성합니다. 수치 오류·유효 응답률과 평가자 점수를 비교하면 통과입니다. 실제 사용자 학습 효과를 입증한 것으로 해석하지 않습니다.
