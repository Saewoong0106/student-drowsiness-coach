# 공부 세션 실행하기

설치는 [Mac·Windows 실행 안내](cross-platform.md)를 따릅니다. 아래 Mac용 `공부_시작.command`·`최근_기록.command`는 Windows에서 각각 `start_study.bat`·`recent_sessions.bat`에 해당합니다. 터미널 명령의 `.venv/bin/python`은 Windows에서 `.\.venv\Scripts\python.exe`로 바꿉니다.

카메라를 열고, 평소 눈 모양을 기억한 뒤, 오래 감긴 눈을 알리고 공부 기록을 남기는 시제품입니다. **눈이 오래 감겼다는 신호**를 찾으며 실제 수면이나 집중도를 판정하지 않습니다.

## 지금 바로 확인할 순서

1. 다른 카메라 미리보기 창을 종료하고 `공부_시작.command`를 더블클릭합니다. 환경 설치는 [첫 실행 안내](first-run.md)를 따릅니다.
2. 처음 10초는 눈을 자연스럽게 뜨고 정면을 봅니다. 보정이 끝나면 `정상 관측`과 공부 시간이 나타납니다.
3. 짧게 깜빡인 뒤, 눈을 약 3초 감았다 뜹니다. 지속 눈 감김은 횟수가 1회 늘고 소리가 한 번 나야 합니다. 눈을 뜬 채 1초 이상 유지하면 다시 정상 상태가 됩니다.
4. 화면을 클릭하고 Space로 휴식합니다. 공부 시간은 멈추고 휴식 시간이 늘어야 합니다. 다시 Space를 누르면 재개합니다.
5. Q 또는 Esc로 종료하고 `최근_기록.command`를 엽니다. 공부·휴식·미측정 시간과 의심 횟수를 확인합니다.

| 키 | 기능 |
|---|---|
| Space | 휴식 / 재개 |
| C | 평소 눈 열림을 다시 보정; 기존 횟수는 유지 |
| M | 소리 켜기 / 끄기 |
| Q 또는 Esc | 기록 저장 후 종료 |

키는 카메라 화면에 초점이 있을 때 동작합니다. 소리가 들리지 않으면 화면의 `소리 켬`, 컴퓨터의 볼륨과 출력 장치를 확인하세요. 카메라 권한을 처음 허용한 직후 창이 뜨지 않으면 프로그램을 종료하고 다시 실행합니다.

## 숫자를 이해하는 5단계

1. **눈 모양:** 눈의 세로 길이를 가로 길이로 나눈 값이 EAR입니다. 눈을 감으면 보통 작아집니다.
2. **개인 기준:** 첫 10초의 가운데 값(중앙값)을 평소 눈 열림으로 사용합니다. 사람마다 눈 모양이 다르기 때문입니다.
3. **시간 조건:** 평소의 65% 미만이 2초 이어질 때 의심 이벤트를 한 번 만듭니다. 짧은 깜빡임은 세지 않습니다.
4. **회복·미측정:** 평소의 75% 이상이 1초 유지되면 이벤트를 닫습니다. 얼굴을 못 찾거나 입력이 0.5초 넘게 끊기면 연결해서 세지 않습니다.
5. **기록 해석:** 공부 시간은 휴식·보정을 제외한 경과 시간입니다. 실제 집중 시간이 아닙니다. 공부 시간은 관측 시간과 미측정 시간의 합이며, 눈 감김 비율의 분모는 관측 시간입니다.

65%·75% 등의 값은 초기 개발 설정이며, 공개 영상과 여러 사용자 시험으로 조정해야 합니다. 보정은 최소 30개 표본, 80% 관측률과 최소 EAR 0.12를 요구합니다. 이 검사만으로 눈을 제대로 뜬 상태임을 보장하지 못하므로 보정 중 직접 정면을 보고 눈을 떠야 합니다.

## 흔한 실수 5가지

| 실수 | 피하는 방법 |
|---|---|
| 보정할 때 눈을 감거나 화면 아래를 봄 | 눈을 뜨고 정면을 봄. 감지가 이상하면 C로 재보정 |
| 얼굴을 놓친 값을 눈 감김 0으로 처리함 | 측정 불가를 별도 상태로 두며 횟수에 넣지 않음 |
| 한 번의 깜빡임을 졸음으로 셈 | 2초 지속 여부와 회복 시간을 확인 |
| 공부 시간이 곧 집중도라고 해석함 | 경과 시간과 관측 가능한 시간으로만 보고 |
| 자동 시험 통과를 실제 정확도로 주장함 | 사람별 조명·안경·자세 시험과 공개 영상 평가를 별도로 수행 |

## 저장과 내보내기

기록은 `data/private/study.sqlite3`에 저장되며 Git에서 제외됩니다. 영상·사진·얼굴 좌표는 저장하지 않습니다. 목표 문구를 입력했다면 그 문구는 시간·횟수·보정 기준과 함께 로컬에 저장됩니다. 실행 중 약 1초마다 및 이벤트 발생·휴식 전환 시 저장하며, 정상 종료 시 최종 저장합니다. 강제 종료된 세션은 `running`으로 남을 수 있으므로 확정 기록으로 해석하지 마세요.

프로젝트 폴더의 터미널에서:

```sh
.venv/bin/python study_session.py --goal '자료구조 복습'
.venv/bin/python session_report.py --list
.venv/bin/python session_report.py --export data/private/export
.venv/bin/python session_report.py --session 세션ID --export data/private/export
```

내보내기는 세션 요약 JSON과 이벤트 CSV를 만듭니다. CSV는 한글을 읽기 쉬운 UTF-8 BOM 형식입니다. 종료되지 않은 이벤트는 종료 시각이 비어 있습니다. 회복 확인 중 표시되는 누적 시간은 임시 값이며, 회복 확인 뒤 실제 회복 시작 시각으로 정정됩니다.

공개 영상도 같은 코드로 분석할 수 있습니다. 영상 분석은 음소거이며 실제 처리 속도 대신 영상 재생 시간을 사용합니다.

```sh
.venv/bin/python study_session.py --video data/raw/example.mp4 --headless --db data/private/video-evaluation.sqlite3
.venv/bin/python session_report.py --db data/private/video-evaluation.sqlite3
```

## 다음 구현 순서

1. 실제 카메라에서 정상·짧은 깜빡임·3초 눈 감김·얼굴 이탈·휴식을 시험하고 실패 상황을 적습니다.
2. 공개 영상의 구간별 정답을 준비해 오탐과 누락을 측정합니다. 영상 단위의 졸음 라벨만으로 순간 이벤트 정확도를 계산하면 안 됩니다.
3. 고개 숙임을 별도로 측정하고 필기·눈 감김·가림 상황을 구분합니다.
4. 세션 통계를 코칭 입력으로 연결하고, 검토된 한국어 문장 쌍으로 LLM 학습·비교를 진행합니다.

현재 고개 숙임, 손으로 눈 가림, 두꺼운 안경, 역광 상황을 안정적으로 구분하지 못합니다. MediaPipe가 가려진 눈 위치를 추정할 수 있어 기하 검사만으로 가림을 검증했다고 볼 수 없습니다. LLM 학습·코칭은 아직 구현하지 않았습니다.

EAR 식 참고: [Soukupová·Čech, Real-Time Eye Blink Detection using Facial Landmarks (2016)](https://cmp.felk.cvut.cz/ftp/articles/cech/Soukupova-TR-2016-05.pdf). 특징점 모델: [MediaPipe Face Landmarker Python 안내](https://developers.google.com/edge/mediapipe/solutions/vision/face_landmarker/python).
