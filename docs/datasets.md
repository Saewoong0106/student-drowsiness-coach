# 공개 데이터 조사와 사용 계획

조사일: 2026-11-05. 공식 배포 설명과 접근 경로를 확인했으며, 대용량 원본 다운로드·압축 해제·샘플 실행까지 검증한 상태는 아닙니다.

## 촬영을 대체할 수 있는 범위

대규모 얼굴 영상 학습용 촬영은 생략할 수 있습니다. 현재 설계는 이미 학습된 MediaPipe로 얼굴을 측정하므로 얼굴 인식 모델을 새로 학습할 필요가 없습니다. 공개 연속 영상으로 판정 규칙을 개발하고, 소량의 실제 책상 환경 영상으로 최종 동작을 확인합니다.

| 목적 | 사용할 데이터 | 직접 촬영 필요성 |
|---|---|---|
| 얼굴·눈 위치 추출 | 사전 학습 MediaPipe 모델 | 대규모 학습 촬영 불필요 |
| 눈 감김 지속시간과 경보 개발 | 공개 연속 영상과 직접 표시한 정답 시간 구간 | 공개 자료로 시작 가능 |
| 필기·고개 숙임·가림 최종 평가 | 실제 사용할 맥북·웹캠의 동의 받은 시험 영상 | 소규모 권장 |
| LLM 미세 튜닝 | 가상 공부 통계와 검토한 한국어 코칭 문장 | 얼굴 촬영 불필요 |

촬영을 전혀 하지 않아도 공개 영상 재생 시제품은 만들 수 있습니다. 이 경우 실제 학생 필기 환경에서 성능을 검증했다는 주장은 할 수 없고, 원래 계획서의 현장 시험 목표도 달성했다고 볼 수 없습니다.

## 공개 자료 비교

### 우선 사용 후보 UTA-RLDD

[공식 배포 페이지](https://sites.google.com/view/utarldd/home) · [공식 페이지가 제공하는 다운로드 폴더](https://drive.google.com/drive/folders/1d_QwgpMXnLY_FmLYXDn7TLcw0D-svXEl)

60명, RGB 연속 영상 180개, 약 30시간이며 전체 용량은 111.3GB로 안내됩니다. 참가자가 집·대학 등에서 휴대폰이나 웹캠으로 촬영했습니다. 각 영상에 정상·각성 저하·졸음의 자기보고 등급이 있습니다. 일반 웹캠 감지 개발에 가장 가까운 후보로 판단합니다.

**핵심 한계:** 영상 전체의 졸음 등급은 매 순간의 눈 감김 정답이 아닙니다. 이벤트 F1을 계산하려면 일부 연속 구간의 눈 감김 시작·종료를 따로 표시해야 합니다. 필기 판별용 정답도 별도로 필요합니다.

먼저 정상·졸음 영상 몇 개로 읽기·특징점 추출 가능성을 확인하고, 이후 사람 단위로 개발·검증·시험 묶음을 나눕니다. 전체 다운로드를 시작할 필요는 없습니다. 발표에 얼굴 장면을 사용할 때는 공개 허용 대상 여부를 확인합니다. 공식 안내는 60명 중 36명만 얼굴 공개를 허용했다고 설명하며 원 논문 인용을 요구합니다.

### 국내 보조 후보 AI-Hub 운전자 상태 정보

[졸음운전 예방을 위한 운전자 상태 정보 영상](https://aihub.or.kr/aihubdata/data/view.do?aihubDataSe=data&currMenu=120&dataSetSn=173&topMenu=)

제공 유형은 이미지입니다. 상세 표에는 1,000명·335,000장이 제시되어 있습니다. 소개의 반올림된 ‘35만’과 구분합니다. 얼굴 영역·특징점과 눈 감김·방향 인식에 관련된 자료이며, 내국인만 신청 가능하다고 안내합니다.

얼굴과 눈의 측정이 잘 되는지 확인하는 보조 자료로 검토합니다. 파일 목록·이용 조건·시간 순서와 타임스탬프 제공 여부는 실제 신청 후 확인해야 합니다. 개별 이미지에 2초 지속 조건을 적용할 수는 없습니다. 이름에 ‘영상’이 있다고 연속 동영상 제공을 가정하지 않습니다.

### 확장 후보 YawDD

[공식 IEEE DataPort 배포](https://doi.org/10.21227/e1qm-hb90)

차 안에서 정상 행동·말하기·노래·하품을 촬영한 RGB 영상입니다. 두 묶음은 322개와 29개 영상으로 안내되며 다운로드 파일은 약 4.94GB입니다. 연구용 사용이 안내되어 있고 파일 접근에는 무료 IEEE 계정 로그인이 필요합니다. 발표용 이미지 공개 여부는 참가자별 정보를 확인합니다.

하품 기능을 나중에 추가할 때 사용합니다. 현재 필수 범위는 눈 감김·고개 숙임이므로 초기 개발에서는 제외합니다. 하품 정답을 눈 감김 정답으로 바꾸지 않습니다.

### 교실 행동 확장 후보 SCB-Dataset3

[원 논문](https://arxiv.org/abs/2310.02522) · [저자 배포 저장소](https://github.com/Whiffe/SCB-dataset)

논문에는 5,686장·45,578개 라벨과 손들기·읽기·쓰기·휴대폰 사용·고개 숙임·책상에 엎드리기 행동이 설명되어 있습니다. 교실 전체 행동을 탐지할 때 참고할 수 있습니다. 한 사람의 눈 감김 지속시간을 측정하는 현재 설계와 입력·정답 단위가 다르므로 우선순위는 낮습니다. 저자 저장소의 배포 구성이 바뀔 수 있어 Dataset3 버전과 실제 데이터 이용 조건을 다시 확인합니다.

### 보류 후보 NTHU-DDD와 MRL Eye

NTHU-DDD [공식 주소](https://cv.cs.nthu.edu.tw/php/callforpaper/datasets/DDD/)는 조사 시 연결 시간 초과로 이용 조건과 다운로드를 직접 확인하지 못했습니다. MRL [배포 주소](https://mrl.cs.vsb.cz/eyedataset.html)는 본문 확인이 충분하지 않았습니다. 재배포 사이트만 보고 이용 가능·허용 범위를 확정하지 않고 이번 시작 데이터에서 제외합니다.

## 공개 영상을 실제 시험 자료로 만드는 순서

1. 출처, 데이터 버전, 조건, 원본 파일명, 참가자 ID, 용량을 목록에 남깁니다.
2. 프레임 시간·해상도·촬영 조건을 확인합니다. 시간 정보 없는 사진을 연속 영상처럼 이어 붙이지 않습니다.
3. 사람 단위 분할을 먼저 고정합니다. 같은 사람·같은 원본 영상의 다른 프레임이 개발과 최종 시험에 섞이지 않게 합니다.
4. 연속 구간을 선정합니다. 정상 구간·실패 구간도 포함하며 잘 감지되는 순간만 선별하지 않습니다.
5. 두 명이 눈 감김·고개 숙임·측정 불가의 시간 구간을 표시하고 불일치를 조정합니다. 사람이 표시한 정답을 모델 예측으로 대체하지 않습니다.
6. 보정에는 사전에 정한 방식으로 확인 가능한 눈 뜸·정면 구간을 사용합니다. 졸린 영상의 첫 10초가 정상이라고 가정하지 않습니다. 보정 실패·측정 불가 비율도 보고합니다.
7. 검증 묶음으로 임계값을 정하고 최종 시험 전에 고정합니다. 공개 데이터 원래 벤치마크와 우리 이벤트 시험의 점수는 별도로 표시합니다.

예정 목록 형식: `dataset, subject_id, session_id, path, split, source_url, terms_checked, calibration_available`. 정답 형식: `video_id, event_type, start_s, end_s, annotator, reviewed`.

## 최소한의 자체 시험

계획서의 4명 이상·각 이벤트 30개 이상·정상 및 필기 합계 60분 목표를 유지하는 제안입니다.

- 별도 보정·개발 세션: 1인당 약 5분. 최종 시험과 파일·세션을 구분합니다.
- 최종 시험: 4명 각각 정상·읽기·필기 15분, 이벤트·가림 시험 약 5분.
- 1인당 지속 눈 감김 8회와 고개 숙임 8회로 각각 32개 이벤트를 목표로 합니다.
- 약 80분의 최종 시험과 별도 보정 약 20분입니다. 정상 관측 시간이 부족하면 추가합니다.
- 실제 졸음을 유도할 필요 없이 행동을 재현합니다. 이는 눈 감김·자세 이벤트 시험이지 생리적 졸음 진단 검증은 아닙니다.

동의를 받은 시험 영상은 정해진 기간 로컬에만 보관하고 평가 종료 후 삭제합니다. 평소 사용 중 영상은 기본 저장하지 않습니다.

## 코칭 데이터는 별도로 제작

이번 조사에서 **이 프로젝트의 공부·졸음 통계와 한국어 코칭 정답이 바로 짝지어진 공개 자료**는 확인하지 못했습니다. 일반 상담·한국어 대화 자료를 그대로 쓰면 통계 해석과 숫자 충실성을 가르치기 어렵습니다.

8가지 상황의 가상 통계를 만들고 사람이 검토한 코칭을 붙입니다. 최초 80~100건으로 학습·재로딩을 검증한 뒤 목표 800건으로 확장합니다. 800건은 설계 목표이며 품질을 보장하는 수량은 아닙니다. 합성 자료라는 출처를 유지하며 실제 사용자 관측 결과로 제시하지 않습니다.
