# 눈 감김·공부 기록 시제품 검증

검증일: 2026-11-07. 환경: Apple Silicon MacBook Pro, macOS 27.2, Python 3.11.9. 설치 버전은 `requirements-macos.txt`에 고정했습니다.

## 자동 검사

```sh
.venv/bin/python -m unittest discover -s tests -v
```

**30개 통과**: 기존 미리보기 4개, 눈 측정·시간 판정·세션·저장 22개, 공부 실행·조회 통합 4개.

- 눈의 가로·세로 비율은 실제 픽셀 좌표로 계산하며 영상 종횡비를 반영합니다.
- 짧은 깜빡임은 제외하고 2초 경계에서 한 번만 알립니다. 5·10·30 FPS의 합성 입력에서 같은 이벤트 시각을 얻었습니다.
- 회복을 1초 확인한 뒤 회복 시작 시각으로 종료를 기록합니다.
- 얼굴 미검출·입력 간격 초과·휴식·재보정이 연속 눈 감김을 끊습니다.
- 보정 시간은 공부 시간에서 제외합니다. 미측정과 관측 시간의 합이 공부 시간과 일치합니다.
- 보정 표본·관측률이 부족하면 재시도합니다. 측정 불가와 NaN을 눈 감김 0으로 바꾸지 않습니다.
- 같은 이벤트를 여러 번 저장해도 하나만 남고, 종료 시각 갱신·DB 재열기·JSON/CSV 내보내기가 동작합니다.
- 실제 실행 프로그램에 얼굴 없는 생성 영상을 넣었을 때 잘못된 보정·이벤트 없이 종료되고 DB와 조회 결과가 연결됩니다.
- 없는 영상·손상된 DB·종료 조건 없는 화면 없는 카메라 실행에 오류를 안내합니다.

## 샘플 영상 통합 확인

[MediaPipe 공개 portrait 이미지](https://storage.googleapis.com/mediapipe-assets/portrait.jpg)를 반복한 임시 영상(130프레임, 10 FPS)으로 모델 추론·보정·저장·조회 경로를 확인했습니다. 보정 10.0초, 이후 공부 기록 2.9초, 이벤트 0회로 종료했습니다. **정지 사진 반복이므로 졸음 감지 정확도·실제 동작 평가 자료가 아닙니다.** 영상과 DB는 저장소에 포함하지 않았습니다.

## 실제 카메라 확인

MacBook 카메라에서 새 공부 프로그램을 실행했습니다. 보정 완료, 여러 눈 감김 이벤트 생성, 회복 시 이벤트 종료, 정상 종료 후 SQLite 기록 재조회가 실행 로그와 로컬 DB에서 확인됐습니다. 개인 세션 원자료는 `data/private/`에만 보관하고 Git에 올리지 않습니다.

이 결과는 입력부터 저장까지 연결된다는 증거입니다. 사용자가 실제로 어떤 동작을 했는지에 대한 구간별 정답이 없으므로 감지 정확도를 의미하지 않습니다. 소리 청취, 짧은 깜빡임 무경보, 실제 휴식 키 동작은 사용자 확인이 필요합니다.

한국어 상태·숫자·키 안내는 카메라 영상 대신 단색 배경을 넣은 화면 렌더링으로 잘림 없이 표시되는지 확인했습니다. 실제 얼굴 이미지는 저장하지 않았습니다.
