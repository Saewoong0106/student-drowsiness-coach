# 첫 실행 확인 기록

확인일: 2026-11-07. 이 기록은 얼굴 위치 표시 시제품의 실행 확인이며 졸음 감지 성능 평가는 아닙니다.

## 환경

- MacBook Pro, Apple M4 Pro, 메모리 24GB
- macOS 27.2
- Python 3.11.9, 프로젝트 전용 `.venv`
- MediaPipe 1.2.2, OpenCV contrib 5.0.0.93, NumPy 2.4.6
- 전체 설치 버전: `requirements-macos.txt`
- MediaPipe Face Landmarker 공식 float16 버전 1
- 모델 SHA256: `64184e229b263107bc2b804c6625db1341ff2bb731874b0bcc2fe6544e0bc9ff`

## 확인 결과

| 항목 | 결과 |
|---|---|
| 패키지 의존성 검사 | `pip check` 통과 |
| 공식 예제 얼굴 이미지 | 실제 모델 추론에서 얼굴 1개 검출 |
| 얼굴 없는 검정 이미지 | 1프레임 처리·얼굴 0개 |
| 12프레임 시험 영상 | 전체 12프레임 처리 후 종료 |
| 프레임 제한 | 동일 영상에서 5프레임만 처리 후 종료 |
| 없는 입력 파일 | 오류 안내와 실패 종료 코드 |
| 화면 없는 카메라의 종료 조건 | 프레임 제한이 없으면 실행 거부 |
| 자동 확인 | unittest 4개 통과 |
| 시작 파일 문법 | `zsh -n` 통과 |
| 실제 카메라 미리보기 | 권한 승인 후 재실행, 사용자 정상 표시 확인 |

최초 실행과 별도 진단 실행에서는 카메라 권한이 미확정인 상태로 입력 열기에 실패했습니다. 이후 직접 재실행에서 미리보기 창 열기를 확인했고 사용자가 정상적으로 표시된다고 확인했습니다. 처음 권한을 허용했을 때 자동으로 성공했다고 가정하지 않도록 실행 안내에 재실행 절차를 추가했습니다.

공식 예제 이미지 출처: https://storage.googleapis.com/mediapipe-assets/portrait.jpg . 예제 이미지·원본 영상·모델 파일은 저장소에 포함하지 않았습니다.

## 다시 확인하는 방법

```bash
.venv/bin/python -m pip check
.venv/bin/python -m unittest discover -s tests -v
```

먼저 의존성과 모델을 준비해야 합니다. 자동 확인은 임시 이미지·영상을 생성하며 카메라를 열지 않습니다.

## 남은 확인

- 실제 얼굴이 화면 밖으로 나갔다 돌아오는 상황과 반복 재실행은 사용자 추가 확인이 필요합니다.
- 실제 카메라의 장시간 FPS·경보 지연·가림 강건성은 측정하지 않았습니다.
- 얼굴 특징점의 존재만으로 눈이 잘 보이는 상태임을 보장하지 않습니다.
- PyTorch/MPS·LLM 학습 장치 검증은 아직 진행하지 않아 이슈 #1 전체 완료로 처리하지 않습니다.
- EAR·보정·졸음 판정·알람·저장·LLM은 후속 구현입니다.
